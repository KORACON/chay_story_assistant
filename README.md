# Чайный Ассистент ☕️

Telegram-бот для генерации PDF-ценников для чайного магазина «Чайная История».

## Возможности

- Ценники для чая (банки 70×70 мм и коробки 160×20 мм) — загрузка данных из Excel, генерация ZIP-архива с PDF
- Ценники для товаров (двухсторонние карточки с названием, ценой и сроком хранения)
- Визитки для чаевых с QR-кодом
- Управление доступом: администраторы могут добавлять/удалять пользователей

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните:
   ```bash
   cp .env.example .env
   ```
4. Укажите в `.env`:
   - `BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
   - `ADMIN_IDS` — Telegram ID администраторов через запятую

## Запуск

```bash
python bot.py
```

## Структура проекта

- `bot.py` — точка входа, инициализация бота и диспетчера
- `handlers.py` — обработчики команд и FSM-состояния
- `render.py` — генерация PDF-ценников и визиток, парсинг Excel
- `access.py` — управление доступом пользователей
- `assets/` — фоновые изображения для ценников
- `fonts/` — шрифт Unbounded

## Требования

- Python 3.10+
- Зависимости из `requirements.txt`
